# 风从海上来

山东省海上风电交互式数据可视化平台。

## 运行

```powershell
cd qingdao_wind_story
python -m pip install -r requirements.txt
streamlit run app.py
```

## 目录

- `app.py`：Streamlit 主交互页面。
- `data/energy.csv`：2021—2025 年山东海上风电公开并网时序数据。
- `data/wind_sites.csv`：山东沿海公开项目点位、规划/建设容量与项目状态。

## 数据说明

CSV 为本地固定数据快照，来源于山东省政府、发展改革部门和能源主管部门公开资料。年度并网数据与项目规划/建设容量分开呈现；缺失的年度口径保留空缺，不进行插值。减碳页面使用公开项目容量、等效利用小时数和电力排放因子进行模型测算，不代表现场监测值。

## 页面顺序

导航按“发展总览—时序发展—空间分布—减碳效益”组织；发展总览页按照同一顺序汇总三个核心结果。

## 素材接入

`assets/hero.jpg` 作为全站统一背景图使用，不会随导航重复渲染首屏模块；山海鲸仅用于辅助制作视觉素材，不参与核心数据计算。

## 技术说明

核心数据处理和交互逻辑由 Python 编写；Streamlit 负责应用框架，Plotly 负责统计图表，pydeck 负责地理空间图层。山海鲸作为视觉设计辅助工具，背景素材不参与核心数据计算，各功能模块只呈现与当前导航相关的数据内容。
